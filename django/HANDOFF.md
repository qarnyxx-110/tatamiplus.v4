# وضعیت اتصال فرانت‌اند Django به بک‌اند

این پوشه و فایل‌های Django در مخزن فرانت‌اند، مسئول قالب‌ها، CSS و JavaScript مرورگر هستند. مخزن بک‌اند `Radinsharifi/Tatami-demo` در این مرحله فقط مرجع قرارداد و محیط تست است و هیچ فایل Python یا migration آن از این مخزن تغییر نمی‌کند.

## قراردادهای قابل استفاده اکنون

- ورود: `GET/POST /accounts/login/` با `username` و `password`؛ فیلد مخفی اختیاری `next` و نشست Django.
- ثبت‌نام: `GET/POST /accounts/register/` با `username`، `email`، `role`، `password1` و `password2`. نقش‌های معتبر فقط `student` و `coach` هستند.
- خروج: `POST /accounts/logout/` با CSRF.
- فروشگاه: `GET /store/`، جزئیات `/store/<slug>/`، سبد `/store/cart/` و مسیرهای POST به‌روزرسانی/حذف اقلام.
- سبد مهمان در نشست Django ذخیره می‌شود و پس از ورود با سبد کاربر ادغام می‌شود.
- ثبت درخواست مربیگری و وضعیت آن در مسیرهای اپ `coaches` وجود دارد.

## موارد مسدود به‌علت نبود قرارداد بک‌اند

| قابلیت در سند کارفرما | وضعیت واقعی | وابستگی لازم |
|---|---|---|
| ورود با شماره موبایل و OTP پنج‌رقمی | وجود ندارد؛ ورود فعلی username/password است | مدل/فیلد شماره موبایل، سرویس SMS، صدور/اعتبارسنجی/ارسال مجدد OTP، محدودسازی تلاش و مسیرهای session |
| نقش باشگاه و حساب باشگاه | مدل کاربر فقط هنرجو و مربی دارد | نقش و مدل باشگاه، فرم/مجوز/مسیرها و تعریف مالکیت حساب |
| تکمیل پروفایل نقش‌ها | فقط ثبت‌نام پایه؛ پروفایل هنرجو/باشگاه وجود ندارد | مدل‌ها و فرم‌های توافق‌شده برای فیلدهای پروفایل |
| ۲۴ محصول در هر صفحه | view فعلی ۱۲ محصول در هر صفحه برمی‌گرداند | تغییر paginator در بک‌اند |
| مرتب‌سازی جدیدترین/پرفروش‌ترین و فیلتر موجودی/برند/نوع | قرارداد فعلی فقط جست‌وجو، دسته، سایز، رنگ، سطح، بازه قیمت و name/price_asc/price_desc را دارد | فیلدهای مدل و گزینه‌های فرم/ویو |
| شمارندهٔ سبد در هدر و HTMX بدون رفرش | context processor شمارنده و endpointهای HTMX تعریف نشده‌اند | context processor و پاسخ‌های partial/OOB برای add/update/remove |
| آدرس، استان/شهر، روش ارسال، سفارش و checkout | هیچ مدل/ویو/URL برای این گردش‌کار وجود ندارد | توافق و توسعهٔ بک‌اند برای آدرس، هزینه و روش ارسال، سفارش، رزرو موجودی و وضعیت |
| پرداخت و صفحهٔ نتیجه | هیچ order/gateway/callback/status وجود ندارد | درگاه واقعی، verify سمت سرور، مدل سفارش/تراکنش و state machine |

تا زمان ایجاد قراردادهای بالا، رابط کاربری نباید وضعیت ساختگی موفقیت OTP، ثبت سفارش، تراکنش یا پرداخت را نمایش دهد. سبد فقط سبد اقلام است و صفحهٔ پرداخت فعال نیست.

## تفاوت‌های شناخته‌شدهٔ فرانت‌اند

- `django/static/css/tatami.css` خروجی تولیدشده از `shared/build.js` است؛ آن را دستی ویرایش نکنید.
- در `shared/public/fonts/` فایل WOFF2 محلی پیدا نشده است؛ بنابراین فونت‌ها هنوز از Google Fonts بارگیری می‌شوند. برای حذف وابستگی شبکه باید فایل‌های مجاز و دارای مجوز فونت به مخزن اضافه شوند.
- واحد پول در قرارداد بک‌اند مشخص نشده است؛ متن فعلی صفحهٔ فروشگاه این ابهام را اعلام می‌کند و نباید به‌صورت پیش‌فرض تومان فرض شود.
- نقشه باشگاه‌ها در تمپلیت Django تا زمان تأمین مدل/داده/endpoint مختصات و Neshan Web Key، نقشهٔ متصل و قابل جست‌وجوی واقعی نیست.

## تست و تحویل
