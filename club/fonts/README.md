# فونت محلی (اختیاری)
اگر فایل `.woff2` فونت وزیرمتن در این پوشه باشد، Build به‌طور خودکار `@font-face` می‌سازد، لینک Google Fonts را حذف می‌کند، فایل را Preload می‌کند و در Cache اولیه Service Worker قرار می‌دهد (سازوکار با فایل آزمایشی تست شد؛ با فونت واقعی تست نشده است).
**فایل فونت در این پروژه نیست.** Vazirmatn با مجوز SIL OFL 1.1 منتشر شده؛ فایل را از مخزن رسمی نویسنده (rastikerdar/vazirmatn) دانلود و مجوزش را کنار آن نگه دارید. فایل از منبع نامطمئن یا جعلی استفاده نکنید.
