# tatamiplus.v4

## راهنمای شروع و توسعه

- **معماری فعال فرانت‌اند:** [docs/FRONTEND_ARCHITECTURE.md](docs/FRONTEND_ARCHITECTURE.md)
- **قرارداد اتصال واقعی Django:** [django/STORE_CHECKOUT_FRONTEND_HANDOFF.md](django/STORE_CHECKOUT_FRONTEND_HANDOFF.md)
- **راهنمای ساخت و تست:** از پوشهٔ `shared/`، دستورهای `npm run build` و `npm test` اجرا می‌شوند.
- **تغییر منبع:** فایل‌های `shared/src/` را ویرایش کنید؛ فایل‌های `shared/dist/` و خروجی‌های تولیدشده را مستقیم ویرایش نکنید.

سندهای `shared/PROJECT_ARCHITECTURE.md`، `django/HANDOFF.md` و `docs/API_CONTRACT.md` تاریخی/پیشنهادی‌اند و مرجع اجرای تغییرات فعلی نیستند.
