# راهنمای نگهداری فرانت‌اند Django تاتامی پلاس

این پوشه نسخهٔ فرانت‌اند Django است. صفحهٔ اصلی، فروشگاه، آکادمی آنلاین و پنل‌های مربی به فایل‌های مجزا تقسیم شده‌اند تا تغییر یک بخش باعث دست‌کاری فایل‌های نامرتبط نشود.

## منبع حقیقت

- ساختار عمومی صفحه‌ها: فایل‌های HTML در \`django/templates\`
- توکن‌ها و کامپوننت‌های مشترک: \`shared/src/css\` و خروجی Build در \`django/static/css/tatami.css\`
- استایل اختصاصی صفحهٔ اصلی: \`django/static/css/home-restored.css\`
- استایل صفحات فروشگاه/آکادمی/مربی: \`django/static/css/module-pages.css\`
- رفتار صفحهٔ اصلی و previewهای داده: \`django/static/js/home-restored.js\`

\`preview/index.html\` یک SPA مستقل با داده‌های نمایشی است. تغییر در آن به‌صورت خودکار به صفحات server-rendered Django منتقل نمی‌شود. برای سایت اصلی، فایل‌های زیرِ \`django/templates\` منبع واقعی ساختار هستند.

## صفحهٔ اصلی

\`templates/pages/home.html\` فقط ترتیب بخش‌ها را کنترل می‌کند. محتوا در partialهای مستقل قرار دارد:

| فایل | مسئولیت |
| --- | --- |
| \`pages/home/partials/hero.html\` | Hero و دکمه‌های ورود به مسیرهای فعال |
| \`pages/home/partials/intro.html\` | معرفی پلتفرم |
| \`pages/home/partials/techniques.html\` | داستان اسکرولی سه فن جودو |
| \`pages/home/partials/features.html\` | لینک چهار مسیر موجود: آموزش، مربیان، فروشگاه و حساب |
| \`pages/home/partials/live_feed.html\` | قالب مشترک preview داده‌های واقعی |
| \`pages/home/partials/section_heading.html\` | سربرگ یکسان بخش‌ها |
| \`pages/home/partials/cta.html\` | دعوت به اقدام پایانی |

سه preview صفحهٔ اصلی از صفحات موجود خوانده می‌شوند:

| بخش | صفحهٔ منبع | selector کارت |
| --- | --- | --- |
| دوره‌های آنلاین | \`/club/\` | \`.tp-course-grid > .tp-course-card\` |
| مربیان | \`/coaches/\` | \`.tp-coaches > li\` |
| فروشگاه | \`/store/\` | \`.pg > .pcd\` |

اسکریپت فقط GET هم‌مبدأ می‌فرستد و HTML کارت‌های واقعی صفحهٔ منبع را clone می‌کند. هیچ نام محصول، قیمت، موجودی، مربی یا دوره‌ای در JavaScript ساخته نمی‌شود. اگر صفحه خالی باشد، پیام خالی همان منبع نمایش داده می‌شود؛ اگر درخواست شکست بخورد، لینک مستقیم به بخش حفظ می‌شود.

**برای تغییر صفحهٔ اصلی:** متن/ساختار را در partial مربوطه تغییر دهید؛ ظاهر را در \`home-restored.css\`؛ رفتار feedها یا داستان اسکرولی را در \`home-restored.js\`. اگر کلاس کارت در صفحهٔ منبع Django عوض شد، selector همان feed در \`pages/home.html\` باید هماهنگ شود.

## فروشگاه

- \`templates/store/product_list.html\`: جست‌وجو، دسته‌بندی، فیلتر، مرتب‌سازی، کارت محصول و صفحه‌بندی.
- \`templates/store/product_detail.html\`: گالری تصویر، توضیحات، تنوع و فرم افزودن به سبد.
- \`templates/store/cart_detail.html\`: سبد خرید، تعداد، حذف/به‌روزرسانی و خلاصه سفارش.
- داده‌ها از context و فرم‌های فعلی Django می‌آیند؛ مبلغ، موجودی و تنوع از مرورگر معتبر فرض نمی‌شوند.
- استایل این صفحات در بخش \`Store\` فایل \`static/css/module-pages.css\` است.

## آموزش آنلاین و پنل مربی

- \`templates/club/course_list.html\`: فهرست دوره‌های منتشرشده و فیلتر مربی/سطح/جست‌وجو.
- \`templates/club/course_detail.html\`: معرفی دوره، مربی، قیمت، وضعیت دسترسی و فهرست قسمت‌ها.
- \`templates/club/episode_play.html\`: پخش ویدیوی محافظت‌شده از route واقعی stream و ثبت اتمام قسمت.
- \`templates/club/coach_detail.html\`: پروفایل مربی در بستر باشگاه مجازی و دوره‌های منتشرشدهٔ او.
- \`templates/club/coach/course_list.html\`: فهرست دوره‌های مربی.
- \`templates/club/coach/course_form.html\`: ساخت/ویرایش دوره و نمایش قسمت‌های آن.
- \`templates/club/coach/episode_form.html\`: بارگذاری/ویرایش قسمت ویدیو.
- استایل این صفحه‌ها در بخش \`Online academy\` و \`Coach pages\` فایل \`static/css/module-pages.css\` است.

ویدیوها از route امن Django دریافت می‌شوند؛ URL عمومی فایل ویدیو ساخته نمی‌شود. قسمت اول رایگان و وضعیت دسترسی هر قسمت از context سرور تعیین می‌شود.

## پروفایل مربیان و ارتباط با هنرجو

- \`templates/coaches/directory.html\`: فقط مربیان تأییدشده و منتشرشده.
- \`templates/coaches/profile_detail.html\`: پروفایل عمومی مربی.
- \`templates/coaches/portfolio.html\`: ویرایش اطلاعات پروفایل توسط خود مربی؛ انتشار همچنان در اختیار تیم است.
- \`templates/coaches/coach_students.html\`: ساخت کد دعوت، وضعیت کدها و فهرست واقعی هنرجویان.
- \`templates/coaches/join.html\`: پذیرش دعوت مربی توسط هنرجو.

فیلدهای عکس، نام، عنوان، بیوگرافی، درجه و باشگاه از مدل واقعی استفاده می‌کنند. امتیاز، تعداد شاگرد، برنامهٔ کلاس یا آمار دیگری که در مدل/ویو وجود ندارد نباید در UI به‌صورت دادهٔ واقعی نمایش داده شود.

## قواعد ویرایش ایمن

1. فقط فایل مربوط به همان بخش را تغییر دهید؛ از تغییر یک فایل عمومی برای حل مشکل تک‌صفحه‌ای خودداری کنید.
2. برای ظاهر مشترک از توکن‌ها و کامپوننت‌های \`--tp-*\` استفاده کنید.
3. CSS اختصاصی صفحات را در \`module-pages.css\` و CSS خانه را در \`home-restored.css\` نگه دارید؛ selectorهای این فایل‌ها باید با ریشهٔ صفحه محدود بمانند.
4. نام فیلدهای Django، route nameها، method فرم‌ها، CSRF و context را تغییر ندهید مگر با قرارداد صریح بک‌اند.
5. بعد از تغییر کلاس HTML هر کارت در صفحهٔ منبع، preview همان کارت در صفحهٔ اصلی را نیز بررسی کنید.
6. پس از انتقال، \`manage.py check\`، تست GET صفحات اصلی، بررسی رندر templateها و \`collectstatic\` اجرا شود.

## مرزبندی بک‌اند

این تغییرات فقط template، CSS و JavaScript فرانت‌اند هستند. هیچ Model، View، URLConf، Form، endpoint، migration، setting، منطق سفارش، پرداخت، موجودی یا مجوز ویدیو تغییر نمی‌کند. قابلیت‌هایی که route و دادهٔ واقعی Django ندارند (مانند تورنمنت، نقشهٔ عمومی باشگاه‌ها، بلاگ، تاتامی‌پدیا، AI و داشبوردهای نمونهٔ Preview) به‌عنوان قابلیت عملیاتی وارد این صفحات نشده‌اند.
