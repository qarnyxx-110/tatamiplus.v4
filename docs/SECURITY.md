# یادداشت امنیتی فرانت‌اند

## انجام‌شده
- **داده localStorage غیرقابل‌اعتماد است:** `state-guard.js` هنگام بارگذاری `cart/fav/saved/prog/lastWatched/role` را اعتبارسنجی و بازنویسی می‌کند (شناسه‌ها باید موجود باشند، تعداد ≤ موجودی، پیشرفت ۰..۱۰۰، گزینه‌ها از فهرست مجاز). متن گزینه‌ها هنگام نمایش `esc()` می‌شود. (قبلاً تغییر دستی `localStorage` می‌توانست HTML اجرا کند؛ تست `امنیت: HTML تزریق‌شده…` این را بازتولید و رفع‌شده‌بودن را بررسی می‌کند.)
- `esc()` اکنون `& < > " '` را escape می‌کند. محتوای HTML غنی (مقاله) فقط پس از `sanitizeHtml` (allow-list) نمایش داده می‌شود.
- آدرس و جست‌وجو هرگز بدون escape در HTML نمی‌آیند (تست XSS در جست‌وجو/هش).
- مقدارهای رسانه فقط با `http(s)://` یا مسیر نسبی پذیرفته می‌شوند.

## CSP — بررسی، **فعال نشده**
| مورد | شمار |
|---|---|
| `onclick`/`oninput`/`onchange`/`onload`/`onerror`/`onkeydown` در قالب‌ها | ۶۱ / ۱۱ / ۱۱ / ۹ / ۱ |
| `style="…"` درون‌خطی در قالب‌های JS | ۶۸ |
| بلوک `<script>` و `<style>` درون‌خطی در هر خروجی | ۱ و ۱ |
| منبع خارجی | `fonts.googleapis.com` (فونت) |
`script-src 'self'` با این ساختار صفحه را می‌شکند، پس CSP سخت‌گیرانه اعمال نشد. مسیر پیشنهادی: جایگزینی کنترل‌کننده‌های درون‌خطی با `addEventListener` (یا data-attribute + delegation)، بیرون‌کشیدن اسکریپت/استایل به فایل، میزبانی محلی فونت؛ سپس `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: https:; frame-ancestors 'none'` (به‌اضافه SRI/‌nonce در صورت نیاز). هدرها باید از سمت هاست/بک‌اند تنظیم شوند.

## فقط نمایشی در فرانت‌اند (باید در بک‌اند هم کنترل شود)
نقش‌های هنرجو/مربی/باشگاه و محدودیت‌های مسیر (`deny`)، «مجوز»های پنل مارکتینگ، مخفی‌کردن دکمه حذف، اعتبارسنجی slug/نوع/حجم فایل، پاک‌سازی HTML، زمان‌بندی انتشار، یکتایی slug، سبد و علاقه‌مندی‌ها، قیمت/موجودی، ثبت‌نام مسابقات، پرداخت. هر کاربر می‌تواند `localStorage` و کد سمت کلاینت را تغییر دهد.

## سرویس‌ورکر و فونت
- Cache فونت خارجی تضمین نشده است (بخش DESIGN_SYSTEM). راه‌حل قطعی: میزبانی محلی فونت (`public/fonts`).
- نام Cache سرویس‌ورکر از هش خروجی Build ساخته می‌شود؛ انتشار نسخه جدید ← Cache جدید و حذف قبلی (تست شده).
- پنل مارکتینگ عمداً PWA/سرویس‌ورکر ندارد (صفحه‌های احراز هویت‌شده Cache نشوند).
