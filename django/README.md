# طراحی تاتامی پلاس برای تمپلیت‌های Django

این پوشه شامل رابط سرور-رندر Django برای تاتامی پلاس است: تمپلیت‌ها در `django/templates/` و فایل‌های استاتیک در `django/static/`. معماری فعلی Django templates + CSS + Vanilla JS است؛ این پروژه به React یا SPA جداگانه مهاجرت نکرده است.

## نصب در مخزن بک‌اند

از ریشهٔ مخزن فرانت‌اند، محتوای این دو پوشه را در ریشهٔ مخزن `Radinsharifi/Tatami-demo` کپی/ادغام کنید:

```bash
cp -a django/templates/. ../Tatami-demo/templates/
cp -a django/static/. ../Tatami-demo/static/
```

سپس از ریشهٔ پروژهٔ Django اجرا کنید:

```bash
python manage.py check
python manage.py test
python manage.py runserver
```

در زمان تحویل، بستهٔ GitHub Actions با نام `tatami-django-frontend-handoff` همین مسیرها را با ریشهٔ صحیح backend-relative در ZIP قرار می‌دهد؛ آن را در ریشهٔ پروژهٔ بک‌اند استخراج و فایل‌ها را بازبینی/ادغام کنید.

## ساخت CSS

هر تغییر استایل را ابتدا در `shared/src/css/` یا توکن‌های `shared/src/design/tokens.json` انجام دهید؛ سپس:

```bash
cd shared && node build.js
```

فایل `django/static/css/tatami.css` خروجی ساخته‌شده است و نباید دستی ویرایش شود. CI هم‌گامی خروجی با سورس را بررسی می‌کند.

## قراردادهای واقعی

نام templateها، URLها و فرم‌ها باید مطابق بک‌اند باشد. مسیرهای فعال و فیلدهای واقعی در `django/HANDOFF.md` و سند بک‌اند ثبت شده‌اند. فرم‌های POST باید CSRF داشته باشند؛ مقادیر قیمت/موجودی سمت سرور معتبر می‌شوند و سبد مهمان با session Django نگهداری/پس از ورود ادغام می‌شود.

## تست پیوسته

Workflow با یک checkout موقت از مخزن بک‌اند در revision ثابت `c88d977949897017e848c3ba23b3ec1bcc0a3ebb`، تمپلیت‌ها و استاتیک‌های این مخزن را نصب و `python manage.py check` و `python manage.py test` را اجرا می‌کند. این تست، بررسی URL/template و تست‌های موجود بک‌اند را پوشش می‌دهد؛ جایگزین تست مرورگری واقعی روی هاست نیست.

## محدودیت‌های خارج از اختیار فرانت‌اند

- ورود فعلی username/password است؛ OTP موبایل و ارسال پیامک در بک‌اند وجود ندارد.
- نقش باشگاه، پروفایل کامل نقش‌ها، checkout، آدرس، ارسال، سفارش و درگاه/پرداخت در بک‌اند موجود نیستند.
- فروشگاه فعلی ۱۲ محصول در هر صفحه دارد؛ تغییر آن به ۲۴ نیازمند تغییر view بک‌اند است.
- واحد پول در قرارداد بک‌اند نهایی نشده است.
- فایل WOFF2 محلی در `shared/public/fonts/` موجود نیست؛ بارگیری فونت هنوز به Google Fonts وابسته است.

این موارد در `django/HANDOFF.md` به همراه وابستگی دقیق برای تیم بک‌اند فهرست شده‌اند. هیچ تراکنش، وضعیت سفارش یا موفقیت OTP ساختگی از فرانت‌اند ایجاد نمی‌شود.
