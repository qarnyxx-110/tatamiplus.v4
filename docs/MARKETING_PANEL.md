# پنل مارکتینگ (مدیریت مقاله‌ها)

**خروجی جدا:** `marketing/` — از سه PWA هنرجو/مربی/باشگاه جدا است و هیچ کد مدیریتی در آن‌ها نیست. در این مرحله پنل فقط برای مدیریت مقاله‌ها و دسته‌های مقاله است؛ ماژول تاتامی‌پدیا و مدیریت اصطلاحات آن حذف شده است.

## دو حالت هنگام Build

| حالت | شرایط | معنی |
|---|---|---|
| **API** | `TP_API_BASE=/api/v1 node build.js` | اتصال به بک‌اند مقاله‌ها طبق `API_CONTRACT.md`. |
| **نمایشی** | بدون `TP_API_BASE` | داده‌های مقاله فقط در `localStorage` همین مرورگر؛ ورود نمایشی و غیرعملیاتی. بنر هشدار دائمی نمایش داده می‌شود. |

## قابلیت‌های فعلی رابط

فهرست مقاله‌ها با جست‌وجو، فیلتر وضعیت/دسته و صفحه‌بندی؛ ایجاد و ویرایش عنوان، slug، خلاصه، متن، نویسنده، دسته، برچسب، تصویر شاخص و SEO؛ ذخیره پیش‌نویس؛ پیش‌نمایش؛ انتشار/لغو انتشار؛ زمان‌بندی انتشار؛ حذف با تأیید؛ و اعتبارسنجی تصویر JPEG/PNG/WebP تا ۲ مگابایت.

## حساب و امنیت

حساب و مجوز باید در بک‌اند کنترل شوند. مجوزها: `articles.manage`, `articles.delete`, `media.upload`. مخفی‌کردن دکمه‌ها کنترل امنیتی نیست. درخواست‌های غیر GET باید CSRF معتبر داشته باشند. این پروژه حساب مارکتینگ ایجاد نمی‌کند.

## وبلاگ عمومی

با `TP_API_BASE` فهرست مقاله‌ها از مسیرهای `/public/articles` خوانده می‌شوند. در Preview بدون API، داده نمایشی مقاله ممکن است برای بررسی رابط استفاده شود و باید به‌عنوان نمونه شناخته شود. مسیر مقاله: `#/blog/<slug>`.

## محدودیت‌ها

زمان‌بندی، مجوزها، پاک‌سازی HTML و بارگذاری واقعی تصویر فقط با بک‌اند معتبر عملیاتی‌اند. تست API این مخزن با Mock Server انجام می‌شود و به معنی وجود بک‌اند واقعی نیست.
